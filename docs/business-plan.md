# RebootFocus 사업계획서 (단일 ICP 기준 v3)

## 1) Executive Summary
- 서비스명: RebootFocus
- 한 줄 소개: 전날 계획이 무너지면 다음날까지 다시 못 붙잡는 직장인을 위해, 놓친 일을 실패 맥락에 맞는 다음 행동과 첫 복귀 블록으로 다시 시작하게 만드는 복귀 코치
- 해결 문제: 해야 할 일은 아는데 전날 실패가 다음날까지 이어지는 실행 붕괴
- 제안 가치: 범용 생산성 관리가 아니라 "실패 다음날 복귀"를 설계하는 실행 루프 제공
- 수익 구조: Freemium + Premium 구독
- 주의사항: 유사 상표/상호 여부는 정식 출시 전 법률 검토를 거친다.

## 2) 문제 정의
### 2.1 고객의 실제 문제
- 해야 할 일과 마감은 명확하지만, 하루가 한 번 꼬이면 다음날 첫 집중 블록을 다시 못 잡음
- 미룬 일을 볼수록 죄책감과 회피가 커져 "다시 시작"의 문턱이 높아짐
- 기존 생산성 앱은 계획과 기록은 남기지만, 실패 직후와 실패 다음날의 복귀 행동까지는 설계하지 않음
- 실패를 의지 부족으로 해석해 문제를 반복하고, 결국 앱 자체를 이탈함

### 2.2 기존 대안의 한계
- 할 일 관리 앱: 목록 정리는 되지만 복귀 순간에 필요한 행동 제안이 없음
- 타이머 앱: 세션은 측정되지만 실패 이후 재시작 루프가 약함
- 코칭/커뮤니티: 비용과 운영 부담이 커서 일상적으로 붙이기 어려움
- 범용 생산성 앱: 메시지가 넓어서 "나를 위한 제품"이라는 감각을 만들기 어려움

## 3) 타깃 고객
### 3.1 초기 ICP (단일 세그먼트)
- 25~34세 지식노동 직장인
- 캘린더/메신저/노션/투두 앱을 이미 일상적으로 사용 중인 사용자
- 전날 계획이 무너지면 다음날 오전까지 복귀하지 못하는 패턴이 반복되는 사용자
- 생산성 앱을 여러 번 설치했지만 1~2주 안에 이탈한 경험이 있는 사용자

### 3.2 검증 전 제외 범위
- 취준생
- ADHD 성향 성인 사용자
- 팀/스터디 운영자(B2B 라이트)

## 4) 제품 제안 (무엇을 파는가)
### 4.1 핵심 가치 제안
- 단순 타이머가 아니라 실패 직후와 실패 다음날의 행동까지 설계하는 복귀 시스템
- 실패를 없애는 것이 아니라 실패 후 복구 시간을 줄이는 제품
- Brain Dump와 Big3는 생산성 장식이 아니라 "다음날 복귀"를 위한 준비 단계
- 뽀모도로/집중 타이머는 핵심 가치가 아니라 복귀 행동을 실행시키는 보조 인터랙션
- 복귀 데이터를 기반으로 같은 실패 패턴을 더 짧게 끊어내는 개인화 기반을 만든다

### 4.2 대표 사용자 시나리오
1. 사용자가 전날 밀린 업무를 Brain Dump로 빠르게 쏟아낸다.
2. 오늘 다시 붙잡아야 할 Big3를 고른다.
3. 가장 부담이 낮은 첫 시간 블록을 배정한다.
4. 실패 시 10분 재시작 블록 또는 더 작은 다음 행동을 제안받는다.
5. 주간 회고에서 "왜 다음날까지 끌렸는지"와 "무엇이 복귀를 만들었는지"를 확인한다.

## 5) 제공 기능 (판매/데모 기준)
### 5.1 MVP 기능 (복귀 엔진)
- Brain Dump 입력(전날 밀린 일 포함)
- 오늘 Big3 선택
- 타임박싱(첫 복귀 블록 우선 배정)
- 집중 세션 기록(시작/완료/중단)
- 실패 사유 체크인 + 10분 재타임박싱/더 작은 다음 행동 제안
- 주간 회고(복귀율, 계획 대비 실행률, 시간 예측 오차)

### 5.2 검증 후 확장
- 공유 결과 페이지
- 딥링크 온보딩 최적화
- 복귀 실패 패턴 분석 고도화
- 고급 AI 코칭

## 6) 비즈니스 모델
### 6.1 수익화 구조
- Free: Brain Dump, Big3, 첫 복귀 블록 타임박싱, 세션 기록, 실패 체크인, 10분 재시작, 기본 주간 요약
- Premium: 4주 이상 추세 비교, 시간대별 실패 분포/피크 실패 시간, 반복 실패 패턴 분석, AI 회고, 개인화 복귀 코칭
- 무료/유료 기능 경계 source of truth: `docs/PRICING_ENTITLEMENT.md`

### 6.2 가격 정책 (가안)
- 월 구독: 9,900원
- 연 구독: 89,000원
- 가격 정책은 실험 기반으로 확정한다(월 9,900원 vs 12,900원 A/B).

### 6.3 매출 가정 방식 (Blended ARPPU)
- 월간제 비중: 60%
- 연간제 비중: 40%
- 월간제 기여: 9,900원 * 0.6 = 5,940원
- 연간제 기여: (89,000원 / 12) * 0.4 = 2,966원
- Blended ARPPU(월): 8,906원

### 6.4 수익 핵심 지표
- Free -> Paid 전환율
- Blended ARPPU
- 월 해지율(Churn)
- LTV/CAC

## 7) 시장 접근 전략 (GTM)
### 7.1 런칭 전
- 랜딩페이지에서 "전날 계획이 무너지면 다음날도 못 시작하나요?" 진단형 메시지로 대기자 모집
- 직장인 생산성/루틴/마감 스트레스 커뮤니티에서 문제 공감형 콘텐츠 테스트

### 7.2 런칭 초기
- 생산성 앱 이탈 경험이 있는 직장인 30~50명으로 4주 유료 베타 운영
- 7/14/21일 체험 A/B 테스트로 전환 최적화
- 페이월 노출 시점(온보딩 직후/첫 회고 직후) A/B 테스트
- 후기 문구도 "집중이 잘 된다"보다 "다음날 다시 붙잡게 됐다"에 맞춰 수집

### 7.3 성장 단계
- 실패 복귀 캠페인(휴면 복귀 시나리오) 운영
- 직장인 업무 루틴 뉴스레터/커뮤니티 제휴 테스트
- 동일 ICP 내 직무별 메시지 세분화 실험

## 8) 운영 지표 (KPI)
### 8.1 제품 지표
- 가입 후 24시간 내 첫 세션 시작률
- 첫 실패 후 24시간 내 재시작률(Recovery24, 메인)
- 첫 실패 후 48시간 내 재시작률(Recovery48, 보조)
- 재시작 횟수(RestartCount24/48)
- 평균 복귀 시간(TTR, Time To Recovery)
- 집중-휴식 사이클 완료율(CycleCompletionRate)
- 계획 대비 실행률(PlanExecutionRate)
- 시간 예측 오차(EstimationError)
- D1 / D7 / D30 리텐션
- 주간 회고 열람 후 다음 행동 실행률
- 주간 회고 열람률

### 8.2 사업 지표
- MAU
- 유료 전환율
- MRR
- 해지율
- 고객 획득 비용(CAC)

## 9) 12개월 목표 (가정 기반)
- 3개월: 베타 사용자 150명 / 유료 전환율 8%
- 6개월: MAU 1,500 / 유료 전환율 6%
- 12개월: MAU 4,000 / 유료 전환율 7%
- 12개월 MRR 가정치(Blended): 유료 사용자 280명 * 8,906원 = 2,493,680원
- 시나리오 운영:
- Base: 전환율 6.0%, 월 해지율 8%
- Good: 전환율 8.0%, 월 해지율 6%
- Bad: 전환율 4.0%, 월 해지율 10%

## 10) 경쟁/차별화
### 10.1 경쟁군
- 할 일 관리 앱
- 포모도로/집중 타이머 앱
- 코칭 기반 생산성 서비스

### 10.2 차별화 포인트
- 실행 자체보다 "실패 다음날 복귀"를 설계한 UX
- 범용 생산성 사용자가 아니라 생산성 앱 이탈 경험이 있는 직장인만 먼저 겨냥
- 실패 이벤트를 데이터로 해석해 개인화 피드백을 제공하는 구조

## 11) 주요 리스크와 대응
- 리텐션 저하: 실패 복귀 UX와 알림 실험 강화
- 세그먼트 흐림: 직장인 외 세그먼트 확장은 핵심 KPI 충족 전까지 보류
- 전환율 저하: 무료 구간 가치 재설계, 가격/패키지 A/B 테스트
- 품질 리스크: 핵심 플로우 모니터링 및 장애 대응 체계 고도화
- 신뢰 리스크: 데이터 처리 정책과 고객지원 SLA 명문화
- 법률/브랜드 리스크: 명칭/상표 사전 검토 완료 후 정식 브랜드 확정

## 12) 실행 로드맵 (사업 관점)
1. 복귀 엔진 완성: 시작 -> 실패 체크인 -> 10분 복귀 재시작 + 24시간 내 재시작
2. 유료화: 구독 상품과 결제 플로우 확정
3. 성장 채널: 직장인 커뮤니티/뉴스레터 중심 획득 실험
4. 운영 고도화: 관측성/실험 체계 구축
5. 확장 판단: 동일 ICP에서 지표가 고정된 후에만 인접 세그먼트 검토

## 13) 제안 문구 (세일즈 피치)
- RebootFocus는 전날 계획이 무너지면 다음날까지 다시 못 붙잡는 직장인을 위해, 놓친 일을 실패 맥락에 맞는 다음 행동과 첫 복귀 블록으로 다시 시작하게 만드는 복귀 코치 서비스입니다.
- 우리는 집중 시간을 기록하는 앱이 아니라 실행 복귀율을 높이는 시스템을 제공합니다.
