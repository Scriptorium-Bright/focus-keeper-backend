# RebootFocus Product Value Q&A

> Version: v0.1  
> Updated: 2026-03-18  
> Scope: 제품 핵심 가치, 복귀 제안의 의미, 타깃 적합성에 대한 내부 질문과 답변 정리

## 1. 목적

- 이 문서는 RebootFocus의 핵심 가치가 어디에 있는지 흔들릴 때 다시 확인하는 내부 Q&A다.
- `복귀 알람`만으로 충분한지, `to-do + 실행 + 복귀` 중 무엇이 핵심인지, 어떤 사용자가 가장 절실한지 정리한다.
- 제품 메시지, 기능 우선순위, 타깃 세그먼트 판단에 공통 기준으로 쓴다.

## 2. Q1. 결국 사용자가 일을 놓게 된다면, "복귀하세요" 같은 제안이 큰 의미가 있나?

### 답변

- `복귀하세요`만 말하는 알람은 의미가 약하다.
- 대부분의 사용자는 해야 할 일을 몰라서가 아니라, 다시 시작할 진입점이 너무 커서 멈춘다.
- 그래서 가치가 생기려면 `알람`이 아니라 `맥락 있는 재시작 제안`이어야 한다.

### 의미 있는 제안이 되려면 필요한 정보

- 사용자가 어떤 일을 놓쳤는지
- 원래 어느 시간대에 하려 했는지
- 실제로 시작했는지, 중간에 끊겼는지
- 실패 이유가 무엇이었는지
- 지금 다시 시작하기 가장 쉬운 다음 행동이 무엇인지

### 예시

- 약한 제안:
  - "복귀하세요."
- 강한 제안:
  - "2시에 하려던 제안서 작업이 비었습니다. 지금 10분 버전으로 다시 시작할까요?"
  - "회의 뒤에 끊긴 작업이라면, 첫 문단 수정부터 다시 시작해보세요."

### 결론

- RebootFocus의 가치는 `리마인더` 자체가 아니라 `놓친 일의 맥락을 반영한 재시작 제안`에 있다.

## 3. Q2. 결국 해야 할 일이 메인이 되고, 실행하다 놓치면 복귀 제안이 포인트가 되어야 하는 것 아닌가?

### 답변

- 맞다.
- 이 제품은 `to-do 앱 + 알람`이 아니라 `할 일 -> 실행 -> 이탈 감지 -> 맥락 있는 복귀 -> 패턴 학습`의 루프로 봐야 한다.
- 해야 할 일 정리와 실행 기록은 진입점이고, 차별점은 그 뒤에 사용자가 놓친 순간을 어떻게 다시 붙잡게 하느냐에 있다.

### 핵심 루프

1. 해야 할 일을 정리한다.
2. 오늘 다시 붙잡을 일을 고른다.
3. 실제 시간 블록과 실행을 시작한다.
4. 시작하지 못하거나 중간에 놓친 순간을 감지한다.
5. 실패 맥락에 맞는 다음 행동이나 10분 재시작을 제안한다.
6. 어떤 시간대와 어떤 종류의 일이 자주 무너지는지 학습한다.

### 이 구조에서 데이터로 봐야 하는 것

- 계획된 시간대
- 실제 시작 여부
- 중단 시점
- 실패 이유
- 재시작까지 걸린 시간
- 시간대별 실패 패턴
- 업무 종류별 실패 패턴

### 결론

- 이 제품의 포인트는 `할 일 관리`가 아니라 `이탈 감지 + 재시작 제안 + 실패 패턴 학습`이다.
- 따라서 기능 우선순위도 단순 통계나 장식 기능보다, 복귀 제안 정확도를 높이는 쪽에 둬야 한다.

## 4. Q3. 결국 잘 해내는 직장인에게도 필요한가?

### 답변

- 완전히 필요 없지는 않지만, 1차 타깃으로는 약하다.
- 평소 잘 해내는 사람은 고통이 덜하고, 기존 도구로도 어느 정도 버틴다.
- 그래서 초기 ICP는 여전히 `자주 무너지고 복귀가 느린 직장인`이 맞다.

### 그래도 매력을 느낄 수 있는 잘하는 직장인

- 평소엔 잘하지만 특정 시간대에 자주 무너지는 사람
- 중요한 블록이 무너지면 손실이 큰 사람
- 반복 패턴을 줄이고 실행 안정성을 높이고 싶은 사람

### 이들에게 줄 수 있는 가치

- 내가 언제 자주 무너지는지 보여준다.
- 무너져도 빨리 복귀하게 도와준다.
- 중요한 업무 블록이 완전히 사라지지 않게 보호한다.

### 결론

- 1차 ICP:
  - 자주 무너지고 복귀가 느린 직장인
- 2차 확장:
  - 평소엔 잘하지만 특정 순간에 자주 끊기는 직장인
- 지금 단계에서 `잘하는 직장인 전체`를 메인 타깃으로 넓히면 다시 메시지가 흐려진다.

## 5. 제품 핵심 가치 문장

### 내부 기준 문장

RebootFocus는 전날 계획이 무너지면 다음날까지 다시 못 붙잡는 직장인을 위해, 놓친 일을 실패 맥락에 맞는 다음 행동과 첫 복귀 블록으로 다시 시작하게 만드는 복귀 코치다.

### 소비자 설명용 문장

RebootFocus는 할 일 앱이 아니라, 놓친 일을 다시 붙잡게 만드는 복귀 앱이다.

### 짧은 피치 문장

- "망친 일정을 다시 붙잡게 해주는 앱"
- "실패한 일을 다음 행동으로 다시 시작하게 만드는 앱"
- "전날 놓친 일을 오늘 다시 붙잡게 만드는 복귀 코치"

## 6. 제품 판단 기준

- 이 기능이 사용자를 더 빨리 다시 시작하게 만드는가?
- 이 기능이 사용자가 놓친 일의 맥락을 더 정확히 반영하는가?
- 이 기능이 특정 시간대/업무 유형의 실패 패턴을 더 잘 해석하게 만드는가?
- 이 기능이 일반적인 to-do 앱과의 차이를 더 선명하게 만드는가?

위 질문에 `예`라고 답하지 못하면 우선순위를 낮춘다.
