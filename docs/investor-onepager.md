# RebootFocus 투자용 1페이지

## 1) Problem
- 집중/루틴 카테고리는 수요가 크지만, 신규 앱은 기능 유사성으로 차별화가 어렵습니다.
- 핵심 병목은 "집중 시작"보다 "실패 후 복귀"에 있습니다.

## 2) Solution
- RebootFocus는 이탈 후 48시간 내 재시작을 설계한 복귀 코치입니다.
- 핵심 루프: Brain Dump -> Big3 -> Timeboxing -> 실패 체크인/재타임박싱 -> 주간 회고 -> 재시작

## 3) ICP (초기 단일 세그먼트)
- 25~34세 직장인/취준생
- 기존 생산성 앱 이탈 경험자
- 해야 할 일은 명확하나 실행 지속이 어려운 사용자

## 4) Wedge (초기 해자)
- 카테고리 평균 KPI(완료율) 대신, 복귀 KPI(48시간 내 재시작률)를 핵심지표로 설계
- 복귀 데이터가 쌓일수록 추천 정확도와 개인화 품질이 개선되는 구조

## 5) Product Scope
### MVP (집중 개발)
- Brain Dump + Big3
- 타임박스 배정
- 실패 사유 체크인 + 10분 재타임박싱
- 주간 회고 + 다음 행동 1개 추천

### Deferred (검증 후)
- 팀 플랜, 소셜, 고급 AI 코칭, 고도화된 지수화 기능

## 6) Business Model
- Freemium + Premium 구독
- 가격 가안: 월 9,900원 / 연 89,000원
- Blended ARPPU(가정): 8,906원
- 가격/체험/페이월은 고정이 아니라 실험 기반으로 확정

## 7) Success Metrics
- Activation: 가입 후 24시간 내 첫 세션 시작률
- Core: 첫 실패 후 48시간 내 재시작률
- Core+: TTR(Time To Recovery)
- Core+: PlanExecutionRate, EstimationError
- Retention: D1 / D7 / D30
- Revenue: Free->Paid, MRR, Churn

## 8) Validation Plan (4주 유료 베타)
- 모집: 30~50명
- 운영: 4주 프로그램(앱 + 반자동 코칭 일부 허용)
- 과금 실험: 9,900원~19,000원
- 체험 실험: 7일/14일/21일
- 페이월 실험: 온보딩 직후/첫 회고 직후
- 통과 기준(내부): 첫날 활성화 60%+, 2주차 잔존 35%+, 실패 후 48시간 내 복귀 25%+, 종료 시 유료 지속 의사 20%+

## 9) Key Risks & Mitigation
- 차별화 실패: 기능 확장보다 복귀 루프 정밀화 우선
- 전환 저조: 체험 기간(14~21일) 및 가격/패키지 실험
- 브랜드 충돌: 서비스명 변경 및 브랜드 리런칭
- 법률 리스크: 정식 출시 전 상표/명칭 법률 검토 필수

## 10) Ask
- MVP 고도화 + 4주 유료 베타 실행을 위한 제품/그로스 리소스 확보
- 단기 목표: 복귀율 증명, 중기 목표: 유료 전환 모델 고정
